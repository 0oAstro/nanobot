# Properties Reference

Properties use YAML frontmatter at the top of a note.

```yaml
---
title: My Note Title
date: 2024-01-15
tags:
  - project
  - important
aliases:
  - My Note
status: in-progress
completed: false
---
```

## Common Types

- text
- number
- checkbox
- date
- datetime
- list
- wikilink text

## Default Properties

- `tags`
- `aliases`
- `cssclasses`
